MindCare AI - Personal Wellbeing Helper

A simple, private, Python-based console app for Mental Health Screening and Crisis Detection. Made with only Python built-in libraries.

Problem Students face stress, anxiety, loneliness and low mood but lack a private, immediate platform for early screening, leading to crisis risk.

Solution MindCare AI gives first-level wellbeing support through daily tracking, screening and safe guidance.

8 Core Features Current mood, stress, sleep appetite and energy, emotions and coping, support network, safety and support, joy and resilience, need for professional help.

Other Features Daily Mood Journal 1-10, 7-Day Report, Support Chatbot, Stress-Relief Activities, Mini-Game, CSV Export, Optional Camera Face-Presence Check, Teamwork Module, Admin Panel.

Tech Python 3.8+, Built-in libs: csv, hashlib, hmac, secrets, datetime, pathlib, getpass. Optional: opencv-python. No Database, No Internet.
